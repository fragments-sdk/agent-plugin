# Fragments starter

A few plain components and tokens, so a first frame can be drawn before there is a project.

- It is a starter, not your design system. Nothing here is a rule.
- Fragments keeps this folder and writes it again when the starter changes. Do not keep work in it.
- Nothing is installed here. React comes with Fragments.
- Frames drawn on it are kept under `~/.fragments/frames/`, like any others.

When you have a project, pass its folder as `project`. Frames are then drawn on its own components and tokens.

## What is in it

- `src/styles/tokens.css`: colour, space, radius and type, light and dark.
- `src/components/`: Button, Card, Field, Badge, Stack, Heading and Text.
